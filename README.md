# SoaringMoon's Vibecode Repo

This repository will contain a large number of vibecoded app examples created through Google's AIStudio.

I try to provide both the full app source code, as well as the prompt that generated it if I still have it available.

Due to age, I don't remember which specific models developed each app.

None of these applications use APIs or LLMs to generate any content, they are standalone applications and should work offline.

These examples are provided so that you can point your vibecoding platform of choice at this repo as a starting point.

It also serves as a portfolio of my ability to vibecode applications.

# App List

- Frame Master Architect - `apps/framemaster-architect` - Allows customized 3D editing of residential buildings and their timber framing. This app accounts for each individual board used in the construction, and estimates timber framing cost.
- Solstice Observatory - `apps/the-solstice-observatory` - Displays and exports an attempt at creating an art masterpiece in SVG without the use of image models.
